Write or improve documentation for the specified code. Cover:
- **Public API** — clear docstrings/JSDoc for every exported function, class, and type with params, return values, thrown errors, and usage examples.
- **Module-level** — a brief header comment explaining the module's purpose and how it fits into the larger system.
- **Non-obvious logic** — inline comments explaining *why*, not *what*.
- **README / guides** — update or create user-facing docs if the change affects usage.

Match the existing documentation style and language of the project. Do not alter any runtime code.
