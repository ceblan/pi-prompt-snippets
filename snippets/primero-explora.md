---
name: Primero explora
description: Investiga el código antes de hacer cambios
placement: prepend
order: 1
---
Antes de hacer cualquier cambio, busca a fondo en el código para entender los patrones existentes, las convenciones de nombres, las decisiones de arquitectura y las rutas de código relacionadas. No supongas APIs, ubicaciones de ficheros ni formas de los datos — verifícalos leyendo el código fuente real. Resume brevemente lo que has encontrado (ficheros clave, patrones, dependencias) antes de proponer cualquier edición. Si algo contradice tus expectativas, señálalo explícitamente.
