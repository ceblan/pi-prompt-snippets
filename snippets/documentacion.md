Escribe o mejora la documentación del código indicado. Cubre:
- **API pública** — docstrings/JSDoc claros para cada función, clase y tipo exportados, con parámetros, valores de retorno, errores lanzados y ejemplos de uso.
- **Nivel de módulo** — un comentario de cabecera breve que explique el propósito del módulo y cómo encaja en el sistema general.
- **Lógica no obvia** — comentarios en línea que expliquen el *por qué*, no el *qué*.
- **README / guías** — actualiza o crea documentación de usuario si el cambio afecta al uso.

Respeta el estilo de documentación y el idioma existentes del proyecto. No alteres ningún código en tiempo de ejecución.
