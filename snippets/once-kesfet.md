---
name: Önce keşfet
description: Değişiklik yapmadan önce codebase'i araştır
placement: prepend
order: 1
---
Before making any change, thoroughly search the codebase to understand existing patterns, naming conventions, architecture decisions, and related code paths. Do not guess at APIs, file locations, or data shapes — verify them by reading the actual source. State what you found (key files, patterns, dependencies) in a brief summary before proposing any edits. If something contradicts your expectations, call it out explicitly.
